# TÖRE: Ulu Tarkan — Starter v0.1

Godot 4.7.x için ilk oynanabilir iskelet.

## İçerik
- Responsive dikey mobil arayüz
- Ana menü
- Kut / Halk / Ordu / Hazine / Güven
- JSON tabanlı kart sistemi
- 5 örnek karar kartı
- Kararlara göre stat değişimi
- PC test penceresi 540x960

## Açma
1. ZIP'i çıkar.
2. Godot Project Manager -> Import.
3. `project.godot` dosyasını seç.
4. Import & Edit.
5. Play ile çalıştır.

## Kart ekleme
`data/cards.json` dosyasına yeni kart ekleyebilirsin. Kod tarafına dokunmadan yeni içerik eklenir.
